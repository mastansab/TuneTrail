## 3. AI-Assisted Code Review & Comparison

### AI-Generated vs Manually Refined Code
- **AI-Assisted Scaffolding:** Initial Flask blueprint stubs, SQLite DDL, and React component skeletons were generated rapidly.
- **Human / Senior Engineering Refinements:**
  1. Added `ON CONFLICT(user_id) DO UPDATE` in `UserPreferences` to prevent duplicate preference rows.
  2. Implemented artist/genre diminishing-returns diversity penalty (`0.82 ** artist_counts`, `0.92 ** genre_counts`) in `HybridRecommender` so top-10 lists don't collapse to one artist.
  3. Replaced `pandas`/`sklearn` Cython DLL imports with pure-Python + NumPy implementations in `recommendation_engine/` after discovering Windows Smart App Control blocked unsigned `.pyd` extensions in the local environment, ensuring 100% portability across Windows and Linux/Docker.
  4. Added native `<dialog>` `.showModal()` focus management and `aria-live="polite"` toast announcements in the React frontend.
